Toyota 2023 年通报其云环境因访问密钥硬编码于公开代码仓库而暴露约 26 万客户数据。原文: "A public repository contained an access key that granted access to customer data stored in the cloud." 官方声明将根因归为密钥管理与配置审核缺失, 并承诺引入自动化密钥轮换。
