### C1-1 Run 人工回执 API（claim/start/finish/cancel）

| 项 | 内容 |
|---|---|

## 10. 风险与熔断

| 风险 | 触发信号 | 熔断动作 |
|---|---|---|
| pi 执行体多步任务体验差（单轮补全限制） | 试点演练② 产出质量不达 | R-1 人工回执永为兜底；试点缩窄到单命令任务 |
| 越界未被拦截 | 演练③/④ 任一失败 | 立即停 P4 → revert `pi_executor_enabled` → 修复后重演 |
| run 终态与 artifact 不一致 | 对账差异 > 0 | 停 P4 → 修复登记链 → 回填 |
| 范围蔓延 | 新功能需求混入 | 一律拒绝另立版本 |
| 30 天观测窗不足 | t0 附近流量低 | 如实标「观测中」，不宣称 M-9/M-10 达标 |

**熔断红线**：越界命令在 L4/L3 未被拦截；主干基线外 pytest 失败 2h 未定位；审批快照可被未审批修改。
