CISA 内部威胁缓解指南梳理了内部人员利用合法凭据收集并外发数据的典型链路。案例显示内部者通过企业邮箱批量转发敏感附件, 并在离职前删除审计痕迹。原文: "Malicious insiders used legitimate credentials to collect sensitive data and later destroyed evidence." 指南强调行为基线监测 (UEBA) 与跨部门 insider threat program 的组织化建设。
