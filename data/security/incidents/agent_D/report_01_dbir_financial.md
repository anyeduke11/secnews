## 报告摘要 (金融分册要点)

Verizon 年度数据泄露调查报告金融分册显示, 金融业数据泄露的首要入口是 Web 应用攻击与凭据盗用组合: 攻击者使用窃取的合法员工凭据登录业务系统, 占金融业泄露初始入口的一半以上。得手后攻击者直接在应用内批量检索导出客户记录, 随后将数据经既有命令信道回传至外部服务器, 全程无文件落地, 传统 DLP 难以察觉。

## 关键事实 (evidence 池)

- "攻击者使用窃取的合法员工凭据登录业务系统"
- "得手后攻击者直接在应用内批量检索导出客户记录"
- "随后将数据经既有命令信道回传至外部服务器"
- "金融业数据泄露的首要入口是 Web 应用攻击与凭据盗用组合"
