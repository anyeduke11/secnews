Capital One 2019 年官方披露: 攻击者利用 AWS 元数据接口获取的 IAM 角色凭证访问其 S3 数据。原文: "The attacker exploited a misconfigured web application firewall to obtain credentials listed in the AWS metadata service." 事件导致约 1 亿客户信息暴露, 推动行业收紧 IMDSv2 与最小权限角色配置。
