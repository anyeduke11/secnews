1. **CAS 防重复终态（生产实测）**：步骤 10 后再次 POST finish → `409 E_CONFLICT "status=succeeded (finish requires running)"` —— 验收②「重复提交返回同一结果不产生重复行」在产线成立。
2. **v1_run 事件（R-6 前置）**：outbox `event_type='v1_run'` 共 **3 条**（claimed / started / finished，带 trace_id 与 payload status/outcome）。
3. **审计留痕（L4）**：`audit_log` `run.claim/start/finish` 共 **3 行**（actor=web）。
4. **守卫全过非绕过**：close 时四守卫 (a)(b)(c)(d) 逐一满足——(a) action succeeded；(b) run 终态；(c) artifact accepted；(d) judgment published。
