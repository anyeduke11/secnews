供应链投毒新变种：npm 生态一周内三起恶意包事件的组织化特征

过去七天内，npm 生态接连出现三起高度相似的恶意包事件。安全研究人员最初将其视为孤立事件，但随着构建脚本指纹与域名注册模式的比对展开，一个更令人不安的结论浮出水面：这三起事件极可能出自同一团伙之手。

三起事件均利用维护者账号交接的时间窗口，在 install 阶段植入环境变量窃取脚本。受影响包的累计周下载量约为 48 万次，窃取内容包括 npm token、云厂商凭证与浏览器 cookie 存档。

防御基线建议：锁定依赖版本、启用 npm token 轮转、在 CI 层面拦截 postinstall 网络外联。完整 IOC 清单已由判断层自动同步至知识图谱的 supply-chain 概念节点。
