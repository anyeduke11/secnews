UpGuard 披露 Microsoft Power Apps 默认配置导致 47 个门户 3800 万条记录公开可访问。原文: "Misconfigured Power Apps portals left 38 million records publicly accessible, including COVID-19 vaccination data." 低代码平台默认开放 API 引擎被指是根因, 事件后 Microsoft 更新了默认权限文档。
